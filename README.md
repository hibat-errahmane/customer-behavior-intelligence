# Customer Segment Radar

A machine learning project that groups customers by how they actually behave,
spots the ones quietly drifting away, and raises a flag before they're gone —
no labels, no guesswork, just patterns in the data.

## Status
 Work in progress

## Stack
Python · UMAP · HDBSCAN · Isolation Forest · Pandas

## Structure
- `notebooks/` — analysis notebooks, one per phase
- `src/` — reusable functions
- `reports/` — exported plots and findings
